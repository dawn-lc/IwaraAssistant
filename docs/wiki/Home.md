# 欢迎来到 Iwara Assistant Wiki

**Iwara Assistant** 是 iwara.tv 的浏览器扩展：页面上只留高频的「勾选 / 下载」动作，配置、任务队列、进度与迁移全部在扩展自己的页面完成。

- **Chrome（MV3）与 Firefox（MV2）共用同一份代码**，行为一致。
- **Firefox 已上架 [AMO](https://addons.mozilla.org/firefox/addon/iwara-assistant/)**（自动更新）；**Chrome 应用商店被拒**（内容政策判定，属禁止项），Chromium 系请手动加载。
- 四种下载通道：浏览器内建下载、aria2、iwaradl、打开直链交给外部下载器。
- 系统通知是唯一的结果反馈通道，点一下就能跳到该去的地方。
- 不收集、不向开发者回传任何数据（见 [PRIVACY.md](https://github.com/dawn-lc/IwaraAssistant/blob/main/PRIVACY.md)）。

## 主要功能

| 领域 | 能力                                                                                                          |
| ---- | ------------------------------------------------------------------------------------------------------------- |
| 下载 | 四种通道；路径模板与实时预览；链接预检；批量去重；浏览器通道并发上限；失败重试；元数据 JSON                   |
| 页面 | 卡片复选框与跨标签页选区；全选 / 反选 / 取消；悬浮菜单；手动输入 ID；美化与宽屏；右下角水印；SPA 切页自动重扫 |
| 任务 | 队列分组（需要处理 / 进行中 / 已完成）；进度；重试；移除（先取消下载器）；清空已结束；启动对账；工具栏角标    |
| 配置 | 九个页签；即时保存；界面语言 `auto` / 中文 / English / 日本語；配置校验与默认值                               |
| 迁移 | 只读检测旧版油猴脚本的页面数据库，显式一键导入；配置支持粘贴裸 JSON 或导入迁移包                              |
| 通知 | 仅在后台发生的事件（入队、完成、失败、发现网盘链接）走系统通知                                                |
| 安全 | 钓鱼仿冒站点防护：全屏警告 + 网络层封锁，用户明确「继续访问」后才放行                                         |
| 社交 | 自动关注 / 自动点赞；好友请求批量审批（any / all 模式）                                                       |
| 同步 | 全量投稿分页遍历入库（可暂停 / 继续 / 断点续跑）；订阅流同步；MediaCenter 推送与反向补齐                      |

## 通知与反馈

页面内**不弹 toast、不显示进度条**——所有状态反馈走系统通知，点通知会跳到对应位置：任务相关跳任务队列；发现网盘链接或外部视频失败跳该视频页。失败与「需要处理」的通知会常驻，直到你点掉或在任务队列里处理完。

## 钓鱼仿冒防护

默认开启，无需配置。命中疑似仿冒域名时：页面被替换成全屏警告，同时**在网络层封锁该标签页的所有请求**；只有点「继续访问」（真实点击，页面脚本伪造不了）才会放行，且只对当前主机名有效；离开该站点后规则自动清除。判据是按 `tabIds` 而不是域名（仿冒域名每天换），且必须排除 `main_frame`，否则用户点「离开」也会被拦。
