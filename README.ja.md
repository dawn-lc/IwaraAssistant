iwara.tv 用のブラウザ拡張です。動画の一括ダウンロード・選択・管理を、実際に使いやすい画面にまとめました。ページ上に残すのは頻度の高い「チェック / ダウンロード」の操作だけで、設定・タスクキュー・進捗・移行はすべて拡張機能自身のページで行います。

- **Chrome（MV3）と Firefox（MV2）が同じコードを共有**しており、挙動は一致します。
- 4 つのダウンロード経路：ブラウザ内蔵ダウンロード、aria2、iwaradl、直リンクを外部ダウンローダーに渡す。
- 結果のフィードバックはシステム通知のみで、クリックすれば該当する場所へ移動できます。
- いかなるデータも収集せず、開発者へ送信しません。

> 使い方の詳しい解説とトラブルシューティングは [Wiki](https://github.com/dawn-lc/IwaraAssistant/wiki) にあります。技術的な実装（アーキテクチャ、ブラウザ間の差異、manifest、メッセージプロトコル、テストとリリース）は [docs/](docs/) にまとめており、この文書では使い方だけを扱います。

> [!IMPORTANT]
> **Firefox：AMO で公開済み**。[こちらからインストール](https://addons.mozilla.org/firefox/addon/iwara-assistant/)できます（自動更新）。
> **Chrome ウェブストア：掲載が拒否されました**（2026-10-30、参照 ID `Grey Lithium`：コンテンツ ポリシー / 性的コンテンツ）。これは製品の位置づけに対する禁止事項であり、コードの修正では解消できません。Chromium 系ブラウザでは [Chromium 系の手動インストール手順](docs/07-install-chromium.md) に沿って手動で読み込んでください。機能はストアからインストールした場合とまったく同じです。経緯と判断は[後述](#なぜストアにないのか)を参照してください。

## インストール

| ブラウザ                                      | インストール方法                                                                        | 備考                                     |
| --------------------------------------------- | --------------------------------------------------------------------------------------- | ---------------------------------------- |
| **Firefox 128+**                              | [AMO ストアからインストール](https://addons.mozilla.org/firefox/addon/iwara-assistant/) | 審査済み、自動更新                       |
| Chrome / Edge / Brave / Vivaldi / Opera / Arc | 手動で読み込む（[手順](docs/07-install-chromium.md)）                                   | ストアでは拒否済み。機能はストア版と同一 |

### Firefox（推奨）

[AMO 製品ページ](https://addons.mozilla.org/firefox/addon/iwara-assistant/) で「Firefox に追加」を押し、権限を確認すればインストール完了です。以降はバージョンアップ時に自動更新されます。

- 公開版のバージョン番号は [AMO 製品ページ](https://addons.mozilla.org/firefox/addon/iwara-assistant/) の表示に従います（バッジも同じ出所です）。リリースのたびに AMO の審査を受けるため、ストアの版はリポジトリ最新のコミットより通常 1〜2 日遅れます。すぐに main のコードを使いたい場合は、下の一時的な読み込みを行ってください。
- 最低要件は **Firefox 128**（`strict_min_version`）です。これより古いと AMO 側でブロックされます。
- 公開パッケージは **MV2** なので、LAN 上の aria2 は `http://192.168.x.x:6800/jsonrpc` のままで問題ありません（MV3 のローカルネットワーク制限を受けません）。

リポジトリの最新コードを一時的に読み込む場合：

```bash
npm install    # Node >= 20.11
npm run build  # → dist/chrome、dist/firefox とそれぞれの .zip
```

`about:debugging#/runtime/this-firefox` を開き →「一時的なアドオンを読み込む」→ `dist/firefox/manifest.json` を選びます。一時的に読み込んだ拡張は Firefox の終了時に無効になり、再起動のたびに読み込み直す必要があります。

### Chromium 系（Chrome / Edge / Brave / Vivaldi / Opera）

機能はストアからインストールした場合とまったく同じで、手動で一度読み込むだけです。更新・ロールバック・データの保持・トラブルシューティングを含む完全な手順は **[docs/07-install-chromium.md](docs/07-install-chromium.md)** を参照してください。最短手順は次のとおりです。

**方法 1：ソースからビルド**（Node 20.11 以上が必要）

```bash
git clone https://github.com/dawn-lc/IwaraAssistant.git
cd IwaraAssistant
npm install
npm run build:chrome   # → dist/chrome
```

**方法 2：CI の成果物をダウンロード**（Node は不要。ただし GitHub へのログインが必要で、成果物は 14 日間のみ保持）

[Actions](https://github.com/dawn-lc/IwaraAssistant/actions/workflows/ci.yml) で最新の成功した実行を選び → ページ下部の Artifacts → `extension-zips` をダウンロード → 展開して出てきた `chrome.zip` をさらに展開します。

ディレクトリを用意したら、`chrome://extensions`（Edge は `edge://extensions`）を開き →「デベロッパー モード」を有効化 →「パッケージ化されていない拡張機能を読み込む」→ **`manifest.json` を直接含む**ディレクトリを選びます。その後、開いている iwara のページを再読み込みしてください。

> 成果物は本リポジトリのソース、または本リポジトリの Actions からのみ取得してください。第三者が転載した zip / crx はソースと照合できないため、使わないでください。

### なぜストアにないのか

2026-10-30 に提出した 0.1.31 は **Chrome ウェブストアで拒否**されました。違反種別は「コンテンツ ポリシー」、参照 ID は `Grey Lithium`（性的コンテンツ）で、是正要求は「性的コンテンツに関連するすべてのコンテンツ/コードの削除」、根拠は「当社は、ユーザーをそのようなコンテンツに誘導する製品を公開することはできません」でした。公式のトラブルシューティングページにある該当項目はさらに直接的で、**この拡張機能の主な目的は、露骨な性的コンテンツを提供するウェブサイトを改善することです**と書かれています。

拡張自体は成人向けコンテンツを含まず、表示もしません。コードに露骨な素材はなく、アイコンは自前で描いた SVG、JS はすべてパッケージ内にバンドルされ、サイトのアクセス制限をプロキシしたり回避したりしません。拒否の実際の理由は**対象とするサイト**にあります。すなわち、iwara.tv にのみ作用し、そのサイトが成人向けサイトだからです。これは Chrome の禁止事項であり是正できる項目ではありません（ポリシー原文は「改めて提出」ではなく「公開停止」を求めています）。また、審査提出時に「成人向けコンテンツ」の項目をすでにチェックしていてもこの判定でした。そのため Chrome ウェブストアへの再提出は行いません。

審査を通すために拡張を「汎用ダウンローダー」に変えたり、サイト名を消したりすることはしません。それは同時に、欺瞞行為・キーワードの詰め込み・最低限の機能といった条項に触れることになり、サイトの性質が変わるわけでもありません。同じコードは AMO では承認されています。[Mozilla のコンテンツポリシー](https://extensionworkshop.com/documentation/publish/add-on-policies/)は商標・AUP・米国法に違反しないことだけを求めており、Chrome のような「対象サイト」に対する禁止条項はありません。

`npm install` はリポジトリ同梱の git フックも有効にします（コミット時の自動整形、コミットメッセージの検証、プッシュ前のローカルゲート）。インストールだけして開発しない場合は無視するか、`git config --unset core.hooksPath` で無効にしてください。

### 権限について

拡張はすべてのサイトへのアクセス権限（`<all_urls>`）を宣言しています。用途は次の 2 つだけです。

1. ダウンロード経路のエンドポイント（aria2 / iwaradl / MediaCenter）はユーザーが任意に入力するため、ドメインをあらかじめ manifest に書けません。
2. フィッシング・偽サイト対策では、任意のサイトの**ホスト名**を読まないと判定できません。

この 2 点を除き、拡張は `iwara.tv` 上でのみ動作します。詳しい理由は [docs/03-manifest.md](docs/03-manifest.md#全站-host-权限一次声明两处用途) を参照してください。

## 使い方

### 動画を 1 本ダウンロードする

入口は 3 つで、いずれか 1 つを使います。

| 入口                           | 場所                                                                                   |
| ------------------------------ | -------------------------------------------------------------------------------------- |
| ページ内フローティングメニュー | 動画詳細ページの右端からスライドするメニュー →「現在の動画をダウンロード」             |
| 右クリックメニュー             | 動画リンクまたは動画ページ上で右クリック →「Iwara Assistant → この動画をダウンロード」 |
| 手動入力                       | フローティングメニュー →「手動ダウンロード」で動画 ID を貼り付け（複数は \| 区切り）   |

動画 ID はアドレスバーの `/video/<ID>` に当たる部分です。例えば `https://www.iwara.tv/video/AeGUIRO2D5vQ6F` の ID は `AeGUIRO2D5vQ6F` です。

### 一括ダウンロード

1. 動画一覧ページでフローティングメニュー →「選択ボックスを切り替え」（または `Space` キー）を押すと、カードにチェックボックスが表示されます。
2. ダウンロードするカードにチェックを入れます。メニューには「このページをすべて選択」「このページで選択を反転」「このページの選択を解除」「すべての選択を解除」もあります。
3. フローティングメニュー →「選択したものをダウンロード」。

いくつか補足します。

- **選択範囲はタブをまたいで共有されます**：A タブでチェックした内容は、B タブに切り替えても有効です。
- ダウンロード済み、またはダウンロード中の動画はスキップされ、ダウンローダーに重複タスクが溜まりません。
- 各動画は結論（キュー登録・失敗・スキップ）が出た時点で自動的にチェックが外れます。手動でクリアする必要はありません。
- 一括投入の間隔は 3 秒です（サイト側のレート制限を避けるため）。

### タスクキュー

ツールバーのアイコンをクリック →「キュー」（または拡張のオプションで「キュー」タブを選択）。リストは 3 つのグループに分かれ、**ToDo が常に一番上**に来ます。

| グループ   | 意味                                    | 各行でできること                                                                   |
| ---------- | --------------------------------------- | ---------------------------------------------------------------------------------- |
| 対応が必要 | 失敗 / 第三者のファイル共有リンクを検出 | 「再試行」または「動画ページを開く」（開くとこの ToDo は自動的に削除）             |
| 進行中     | 待機中 / ダウンロード中                 | 進捗の確認。ダウンロード中は「削除」でき、先にダウンロードを中止してから記録を消す |
| 完了       | 完了 / 受け渡し済み                     | 履歴。消去できる                                                                   |

上部の「状態を更新」を押すと、定期走査を待たずに aria2 / iwaradl と即座に突き合わせできます。

### 主要な設定

拡張のオプション →「ダウンロード」タブ：

| 設定                                         | 既定値                                    | 説明                                                                                                           |
| -------------------------------------------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| ダウンロード方法                             | ブラウザ内蔵ダウンロード                  | ほかに aria2 / iwaradl（要エンドポイント設定）、直リンクを開く（受け渡し後は追跡しない）                       |
| 同時ダウンロード数                           | 3                                         | ブラウザ経路にのみ作用。aria2 / iwaradl の並列数はそれぞれが制御する                                           |
| 保存パステンプレート                         | `/Iwara/%#AUTHOR#%/%#TITLE#%[%#ID#%].mp4` | 変数は[パスとファイル名](#パスとファイル名)を参照。入力欄の下にリアルタイムプレビューがある                    |
| 第三者のファイル共有リンクをチェック         | オフ                                      | オンにすると、説明欄やコメントに第三者のファイル共有リンクがあれば**ダウンロードせず**、判断待ちの ToDo を残す |
| ダウンロードリンク検出時にファイル名をコピー | オフ                                      | 第三者のファイル共有リンクを検出したとき、ファイル名をクリップボードに書き込む                                 |

その他のタブ：RPC（エンドポイントと環境の自己診断）、フィルター（一覧の書き換え）、ファイル名（クリーニング規則）、フレンド申請、移行、詳細（実験的機能、表示言語、バックグラウンドの維持）、ガイド。

全項目は [docs/05-features.md](docs/05-features.md#配置与多语言) を参照してください。

### パスとファイル名

パステンプレートは「ダウンロード」タブで設定し、次の変数を使えます（大文字・小文字を区別し、`%#` と `#%` の間が変数名です）。

| 変数             | 意味                                 | 出力例                                |
| ---------------- | ------------------------------------ | ------------------------------------- |
| `%#AUTHOR#%`     | 投稿者のユーザー名                   | `Mr.Quin`                             |
| `%#ALIAS#%`      | 投稿者のニックネーム（空の場合あり） | `摸鱼奎恩`                            |
| `%#TITLE#%`      | 動画タイトル                         | `【Quin】黑暗之魂3 一周目攻略 Part22` |
| `%#ID#%`         | 動画 ID                              | `MrQuinWo22Ne22`                      |
| `%#QUALITY#%`    | 実際にダウンロードした画質           | `Source` / `540` / `360`              |
| `%#UploadTime#%` | 動画の公開日時                       | `2022-02-22`                          |
| `%#NowTime#%`    | 投入時点の現在日時                   | `2022-02-22`                          |

`%#UploadTime#%` と `%#NowTime#%` には [dayjs](https://day.js.org/docs/en/display/format) の書式文字列を付けられます。出現するたびに個別に解釈されます：`%#NowTime:YYYY-MM-DD_HH.mm.ss#%` → `2022-02-22_22.22.22`。書式を付けない場合は常に `YYYY-MM-DD` です（生のタイムスタンプではありません）。

完全な例（Windows のドライブレター、Unix の絶対パス、相対パスに対応。UNC パス \\server\share と `..` による範囲外は拒否され、警告が出ます）：

```text
D:/Iwara/%#AUTHOR#%/(%#ALIAS#%)%#UploadTime:YYYY-MM-DD#%_%#TITLE#%_%#QUALITY#%[%#ID#%].mp4
```

レンダリング結果：

```text
D:\Iwara\Mr.Quin\(摸鱼奎恩)2022-02-22_【Quin】黑暗之魂3 一周目攻略 Part22_Source[MrQuinWo22Ne22].mp4
```

「ファイル名」タブはファイル名の正規化の流れを制御します：NFKC 正規化 → 絵文字の置換 → 結合文字の畳み込み → Windows の不正文字の置換 → 長さの切り詰め（タイトルは既定 72、ニックネームは既定 64）。これらの規則は `%#TITLE#%` と `%#ALIAS#%` にのみ作用し、それ以外の変数はそのまま展開されます。

経路ごとにパスの扱いが異なります：**aria2 / iwaradl** は完全なディレクトリ + ファイル名を受け取り（テンプレートに従ってディレクトリを作成）、**ブラウザ内蔵ダウンロード**はブラウザのダウンロード先からの相対ファイル名しか受け付けないため、ドライブレターとルートは取り除かれ、サブディレクトリは保持されます（どちらのホストもディレクトリを自動作成します）。**直リンクを開く**場合は、ファイル名をヒントとして外部ダウンローダーに渡すだけです。

### 通知

ページ内にトーストは出さず、プログレスバーも表示しません。状態のフィードバックはすべてシステム通知で行います。通知をクリックすると該当する場所へ移動します。

- タスク関連 → タスクキュー
- 第三者のファイル共有リンクの検出 / 外部動画の失敗 → その動画ページ（または外部の元 URL）

失敗と「対応が必要」の通知は、クリックして消すかタスクキューで処理するまで残ります。

### 旧ユーザースクリプトからの移行

拡張のオプション →「移行」タブ：

1. **自動検出**：任意の iwara ページを開くと、拡張は旧スクリプトがページ内に残したデータベースを読み取り専用で検出し、件数を表示します。
2. **明示的なインポート**：移行タブに戻ってインポートを実行します。インポート中はその iwara タブを開いたままにしてください（そのデータはページ自身からしか読めません）。
3. **設定は貼り付けのみ**：旧スクリプトの設定はユーザースクリプトマネージャーの専用ストレージにあり、ページからは読めません。旧スクリプトの「設定をエクスポート」でテキストをコピーし、移行タブの貼り付け欄に貼ってください。本拡張がエクスポートした完全な移行パッケージのファイルをインポートすることもできます。

結果は「書き込み / スキップ / 失敗」の件数としてそのまま表示されます。「インポートに成功しました」の一言でデータの欠損を覆い隠すことはしません。詳しくは [docs/05-features.md](docs/05-features.md#数据与迁移) を参照してください。

### フィッシング・偽サイト対策

既定で有効で、設定は不要です。偽装と疑われるドメインに一致した場合：

1. ページが全画面の警告に置き換わり、同時に**そのタブのすべてのリクエストがネットワーク層で遮断**されます。
2. 「アクセスを続ける」をクリックした場合（実際のクリックが必要で、ページのスクリプトでは偽造できません）にのみ許可され、しかも現在のホスト名にのみ有効です。
3. そのサイトを離れると規則は自動的に削除され、その後の閲覧に影響しません。

## よくある質問

**Chrome ウェブストアで見つからないのはなぜ？**
2026-10-30 に拒否されました。参照 ID は `Grey Lithium`（コンテンツ ポリシー / 性的コンテンツ）で、理由は拡張の「主な用途が、露骨な性的コンテンツを提供するウェブサイトの改善である」ことでした。禁止事項に該当するため、コードの修正では解決できず、再提出もしていません。Chromium 系では手動で読み込んでください。[Chromium 系の手動インストール手順](docs/07-install-chromium.md) を参照。

**読み込んだらブラウザに拡張が「信頼されていない」、またはストア由来ではないと表示された**
ストア以外の拡張に付く固定の表示です（ブラウザのサイドロードに対する方針）。無効にはできませんが、無視して問題ありません。機能には一切影響しません。

**AMO でインストールした版が、リポジトリの新しいコミットより古い**
正常です。AMO はリリースのたびに審査を行うため、ストアの版が push 直後の commit と同じになることはありません。現在、公開版とリポジトリの版は一致しています（0.1.32）。先行して main の最新コードを使う場合は、ローカルで `npm run build` を実行したうえで `dist/firefox/manifest.json` を一時的に読み込んでください。一時的な読み込みとストア版は互いに競合しませんが、2 つのインスタンスが同時に注入されるのを避けるため、どちらか一方だけにしておくことをおすすめします。

**ダウンロードを押したのに始まらず、「対応が必要」に入った**
「第三者のファイル共有リンクをチェック」が有効で、その動画の説明欄またはコメントに第三者のファイル共有リンクがあったためです。これは意図的にダウンロードしていません。動画ページを開いて、ファイル共有リンクを使うかダウンローダーを使うかを自分で判断し、ダウンロードすると決めたら「強制ダウンロード」をクリックしてください。

**動画が「非公開動画」と表示され、再試行しても変わらない**
そうした動画は投稿者の友達にしか見られず、ログイン状態とは関係ありません。投稿者のプロフィールで友達申請し、承認されてから「再試行」を押してください。

**Firefox から LAN 上の aria2 に接続できない**
本リポジトリの Firefox 版は **MV2** であり、Firefox の MV3 拡張に対するローカルネットワークアクセス制限を受けません。LAN の http アドレスもそのまま使えます。自分で MV3 ビルドに変更した場合は `127.0.0.1` か `https` しか使えません（詳細は [docs/02-cross-browser.md](docs/02-cross-browser.md)）。

**タスクが削除できない**
ダウンロード中のタスクは、先にダウンローダー側で中止してから記録を削除する必要があります（「削除」を一度押すと「中止しますか？」に変わり、もう一度押すと実行されます）。状態が「受け渡し済み」（外部ダウンローダーに渡した）の場合、本拡張側で記録を削除しても相手側は停止しません。

**なぜ全サイトへのアクセス権限が必要なのか？**
前述の「権限について」を参照してください。用途は 2 つだけです。

**拡張はデータをアップロードするのか？**
いいえ。すべてのデータはローカルにあります。[PRIVACY.md](PRIVACY.md) を参照してください。

**ダウンロードが遅い、または aria2 で同じタスクが繰り返し作り直される**
まずどの経路かを確認してください。aria2 側は投入時に `max-connection-per-server` と `split` を明示的に補います（既定はどちらも 4 で、「ダウンロード」タブで変更できます）。上流 aria2 のこれら 2 つの既定値は **1** と 20M なので、明示しなければ単一接続となり、小さいファイルは分割されません。それでも遅い場合は、プロキシの帯域、aria2 全体の `max-overall-download-limit`、自分で設定した接続数を確認してください。速度が **16 KiB/s** を下回る状態が 2 回連続のサンプリング（1 分に 1 回）でも続くタスクは自動的に再起動されます（直リンクを再解析して同じ場所でアドレスを差し替えます）。これは意図した動作で、停止ではありません。進捗が 98% を超えている場合は対象外ですが、速度が 0 のときは除外されません（接続が死んでいるためです）。

**タスクが「待機中」のまま動かない**
ブラウザ経路の同時実行上限（既定 3）が効いています。上限を超えたタスクは前のタスクが終わってから開始され、何十本もの転送が同時に同じ CDN へ殺到するのを防ぎます。aria2 / iwaradl に切り替えた場合、「待機中」はそれらの並列上限で決まり、本拡張とは関係ありません。

**解析に失敗する / 権限がないと言われる**
よくあるのは 3 種類です：直リンクの失効（もう一度ダウンロードを押せば再解析されます。aria2 側の 403 もエラー応答に応じて自動的に再構築されます）、希望画質が最後の段まで取得できない（「ダウンロード」タブで希望画質を下げるか、ネットワーク環境を変える）、ログイン状態の失効（iwara.tv に再ログインしてページを再読み込みする）。非公開動画は投稿者と互いに友達である必要があり、こうしたアクセス制御は拡張が回避できる範囲ではありません。

**通知が表示されない**
拡張はシステム通知を唯一のフィードバック手段にしています。まず OS 側でブラウザの通知権限がオフになっていないか、「集中モード / おやすみモード」が有効になっていないか確認してください。通知が抑止されてもタスク自体には影響せず、タスクキューとツールバーのバッジは更新されます。

**拡張をアップデートまたは再インストールするとデータは残る？**
同じ拡張 ID でのアップデートでは失われません。設定・キュー・動画ライブラリは `browser.storage.local` と拡張自身の IndexedDB にあります。ブラウザがデータを消すのは、拡張機能の管理ページで「削除」したときだけです。手動でバックアップしたい場合は「移行」タブで完全な移行パッケージをエクスポートしてください。

**インストールしたのに反応がない / ページにチェックボックスが出ない**
順に確認してください：① iwara のタブを再読み込みしたか（拡張のインストールや更新より前に開いていたページには自動で注入されません）、② 現在のページが動画一覧ページか動画詳細ページか（それ以外のページにはもともとチェックボックスがありません）、③ 「ダウンロード」タブの「チェックボックスを自動挿入」がオフになっていないか（オフでも `Space` キーで手動で有効にできます）、④ Chrome 系では、読み込んだディレクトリが `manifest.json` を直接含むものであり、その親ディレクトリではないか。より詳しい手順は [docs/10-troubleshooting.md](docs/10-troubleshooting.md) を参照してください。
