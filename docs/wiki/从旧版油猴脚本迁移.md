# 从旧版油猴脚本迁移

迁移页（选项 →「迁移」）负责三件事：探测旧数据、导入旧库、导入配置。目标是**不丢数据**，所以每一步都只看得到真实条数，而不是一句「导入成功」。

这里说的「旧版脚本」指 [IwaraDownloadTool](https://github.com/IwaraEnhance/IwaraDownloadTool)：功能基本一致的油猴脚本版，数据可以直接搬过来。

## 一、自动只读检测

打开任意 iwara 页面后，扩展只读探测旧版油猴脚本（IwaraDownloadTool）留在页面里的 IndexedDB，并在迁移页显示能读到多少条。

- 探测是**只读**的：不写、不改、不迁移，直到你点导入。
- 需要那个 iwara 标签页保持打开——只有页面自己的上下文能读到那份数据库。

## 二、显式导入旧库

回到迁移页点导入。结果会如实显示「写入 / 跳过 / 失败」三类条数。

- **为什么必须保持标签页打开**：旧库在页面所在的源下，后台读不到。后台发起、页面转发，跑完给你结论。
- **为什么是分批的**：旧库可能有几万条记录，一次消息传完会被 MV3 的 5 分钟上限杀掉。分批导入同时把进度写进快照，页面实时显示。
- 视频库会做去重与合并：同 ID 取更完整的一份记录，不用较差的覆盖已有的更完整数据。

## 三、迁移配置

旧脚本的配置存在油猴管理器的**私有存储**里，页面读不到，所以只能靠粘贴：

1. 在旧脚本里用「导出配置」复制那段 JSON 文本。
2. 粘到迁移页的粘贴框，点导入。支持裸 JSON，也支持导入本扩展导出的**完整迁移包**文件。

本扩展导出的迁移包包含配置、队列与转换后的视频库记录，也可以拿来做手动备份。

## 常见情况

| 现象                 | 说明                                                                         |
| -------------------- | ---------------------------------------------------------------------------- |
| 检测显示 0 条        | 旧脚本没在这个浏览器 profile 里用过，或它的数据库已被清理                    |
| 导入中途关闭了标签页 | 已写入的批次保留，进度快照停在「已中断」，重开迁移页可再次导入（会跳过已有） |
| 只想搬配置           | 只粘配置 JSON 即可，视频库可以不迁                                           |
| 旧脚本还在用         | 两边可以并存；但**不要同时**对同一批视频投递，去重只在各自一侧生效           |

旧库字段到本扩展的映射见 [docs/05-features.md](https://github.com/dawn-lc/IwaraAssistant/blob/main/docs/05-features.md#数据与迁移) 的「数据与迁移」一节。
