# 路径可用变量

路径模板在「下载」页签配置，支持以下变量（大小写敏感，`%#` 与 `#%` 之间是变量名）：

| 变量             | 说明                 | 使用示例                             | 输出                                  |
| ---------------- | -------------------- | ------------------------------------ | ------------------------------------- |
| `%#NowTime#%`    | 投递时刻的当前时间   | `%#NowTime:YYYY-MM-DD#%`             | `2022-02-22`                          |
| `%#UploadTime#%` | 视频发布时间         | `%#UploadTime:YYYY-MM-DD_HH.mm.ss#%` | `2022-02-22_22.22.22`                 |
| `%#AUTHOR#%`     | 作者用户名           | `%#AUTHOR#%`                         | `Mr.Quin`                             |
| `%#ALIAS#%`      | 作者昵称（可能为空） | `%#ALIAS#%`                          | `摸鱼奎恩`                            |
| `%#TITLE#%`      | 视频标题             | `%#TITLE#%`                          | `【Quin】黑暗之魂3 一周目攻略 Part22` |
| `%#ID#%`         | 视频 ID              | `%#ID#%`                             | `MrQuinWo22Ne22`                      |
| `%#QUALITY#%`    | 实际下载的画质       | `%#QUALITY#%`                        | `Source` / `540` / `360`              |

`%#NowTime#%` 与 `%#UploadTime#%` 的格式串走 [dayjs 的 format](https://day.js.org/docs/en/display/format)，**每次出现的格式独立解析**（同一个模板里可以写两种格式）。不带格式时固定是 `YYYY-MM-DD`，不是原始时间戳。

完整示例：

```text
/Iwara/%#AUTHOR#%/%#NowTime:YYYY-MM-DD#%/(%#ALIAS#%)%#UploadTime:YYYY-MM-DD+HH.mm.ss#%_%#TITLE#%_%#QUALITY#%[%#ID#%].MP4
```

渲染结果：

```text
/Iwara/Mr.Quin/2022-02-22/(摸鱼奎恩)2022-02-22+22.22.22_【Quin】黑暗之魂3 一周目攻略 Part22_Source[MrQuinWo22Ne22].MP4
```

Windows 盘符（`D:/...`）、Unix 绝对路径（`/home/...`）、相对路径都支持；**UNC 路径** `\\server\share` 与靠 `..` 越出根的写法会被拒绝并给出提示。

## 文件名清洗

「清洗」页签控制下面这条链路，**只作用于 `%#TITLE#%` 与 `%#ALIAS#%`**，其它变量原样展开：

| 步骤         | 开关                | 作用                                             |
| ------------ | ------------------- | ------------------------------------------------ |
| NFKC 归一    | `pathNormalize`     | 全角 / 半角、兼容字符统一                        |
| Emoji 替换   | `pathReplaceEmojis` | Emoji 换成 `_`（避免部分文件系统与同步工具出错） |
| 组合符号折叠 | `pathFoldMarks`     | 把「字母 + 组合音标」折成 `_`，避免视觉重复      |
| 非法字符替换 | `pathSanitize`      | `\ / : * ? " < >                                 | `与前导`.`换成`_` |
| 长度截断     | `pathTruncate`      | 标题默认 72、昵称默认 64 字符                    |

## 各通道对路径的用法

| 通道           | 目录部分                              | 文件名部分                           |
| -------------- | ------------------------------------- | ------------------------------------ |
| aria2          | 生效（`dir`），会按模板建目录         | 生效（`out`）                        |
| iwaradl        | **不生效**（目录由 iwaradl 自己配置） | 生效（`filename_template`）          |
| 浏览器内建下载 | 盘符与根被去掉，相对子目录保留        | 生效                                 |
| 打开直链       | 不生效                                | 作为 `download` 参数提示给外部下载器 |

想验证模板是否可用：改完看输入框下方的实时预览；也可以在「RPC」页签点自检——它会用一份假数据把模板渲染一遍，把「写了不存在的变量」「整条模板被清洗成空」这类错误在真正下载之前指出来。
