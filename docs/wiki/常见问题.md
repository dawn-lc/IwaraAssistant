# 常见问题

更系统、按「你看到了什么」组织的排查步骤在仓库的 [docs/10-troubleshooting.md](https://github.com/dawn-lc/IwaraAssistant/blob/main/docs/10-troubleshooting.md)，这里放最常被问到的那些。

## 安装与启用

**Chrome 应用商店里为什么搜不到？**
2026-10-30 提交的版本被拒（内容政策 / 色情内容，参考 ID `Grey Lithium`），理由是扩展「主要用途是改进提供露骨色情内容的网站」。这属于 Chrome 的禁止项而不是可整改项，所以不再重投；Chromium 系请按 [[安装与首次配置]] 手动加载，功能与商店安装完全一致。同一份代码在 AMO 已通过审核。

**加载后浏览器提示扩展「不受信任」或不来自商店？**
非商店扩展的固定标记（浏览器对侧载的策略），无法关闭，忽略即可，不影响任何功能。

**AMO 上装的版本比仓库最新提交旧？**
正常。AMO 每次发版都要审核，商店永远不会等于刚 push 的 commit。要立刻用主干代码就在本地 `npm run build` 后临时载入 `dist/firefox/manifest.json`。临时载入与商店版互不冲突，但建议只留一个，避免两个实例同时注入。

**装了扩展但页面上什么都没有？**
按顺序：① 刷新 iwara 标签页（安装 / 更新后已打开的页面不会自动注入）；② 确认是视频列表页或详情页（其他页面本就没有页内 UI）；③ 检查「下载」页签的「自动注入复选框」是否被关掉（关掉后按 `Space` 也能开）；④ Chromium 系确认加载的是**直接含 `manifest.json`** 的目录。

## 下载

**点了下载，为什么没开始下，而是出现在「需要处理」里？**
开启了「第三方网盘链接检查」，且该视频的简介或评论里有网盘链接。这是刻意不下载：请打开视频页自己选，确认要下再点「强制下载」。

**下载很慢？**
先看通道。aria2 侧投递时已显式补 `max-connection-per-server=4` 与 `split=4`（上游默认是 1 与 20M，不补就是单连接、小文件不分段），可在「下载」页签调高。仍然慢就查代理带宽与 aria2 全局的 `max-overall-download-limit`。速度低于 16 KiB/s 且连续两次采样仍如此的任务会被自动重启，这是刻意行为。

**任务一直停在「排队」？**
浏览器通道的并发上限（默认 3，1~10 可调）在起作用：超出的任务等前一个结束才开跑。aria2 / iwaradl 的「排队」是它们自己的并发上限。

**解析失败 / 提示没有权限？**
常见三类：直链过期（重新点一次下载即可）、首选画质到最后一级都拿不到（调低优先画质或换网络）、登录态失效（重新登录后刷新页面）。

**为什么下载器里会出现「目标文件已存在」这种看不懂的失败？**
同一输出路径上被投递了两次（`errorCode 13`）。扩展对同一 `videoId` 只允许一条任务，并且会先查 aria2 里的活 gid、命中就**接管**而不是再投递一次；历史遗留的重复行点「刷新状态」即会收敛。

**速度慢的时候为什么任务被重建了？**
那是慢速自动恢复：低于 16 KiB/s 且连续 2 次采样仍如此 → 重新解析直链后原地换地址。进度超 98% 豁免，但速度为 0 不豁免（连接已死）。连续重建说明网络或直链本身不通。

## 账号与内容

**视频显示「私有视频」，重试也没用？**
这类视频**仅作者的好友可见**（关注不够，必须互为好友且对方通过）。加好友、对方通过后再点「重试」。见 [[私有与不公开视频]]。

**怎么下隐藏视频？**
列表里看不到，但知道视频 ID 就能下：悬浮菜单 →「手动下载」。见 [[手动下载与批量投递]]。

## 连接与平台

**Firefox 连不上局域网里的 aria2？**
本仓库的 Firefox 产物是 **MV2**，不受 Firefox 针对 MV3 扩展的本地网络访问限制，局域网 http 地址可以直接用。若你自己改成了 MV3 构建，则只能用 `127.0.0.1` 或 `https`。

**任务删不掉？**
正在下载的任务要先取消下载器再删记录（点一次「移除」变成「确认取消？」，再点一次才执行）。「已交付」的任务删记录不代表外部下载器停止。

**关闭浏览器后任务没有继续？**
Chrome MV3 没有常驻后台，进程被杀任务即中断——这是平台限制，扩展无法消除，只能如实告知并在下次启动时做残骸归一（把「存储说在跑、内存里没有」的任务按中断处理，不会留下永远转圈的假状态）。批量入库支持断点续跑。

**通知没有弹出来？**
扩展用系统通知作为唯一反馈：确认操作系统的浏览器通知权限没关、没有开「专注 / 勿扰」。通知被压掉不影响任务，任务队列与工具栏角标仍会更新。

## 数据与隐私

**为什么要全站访问权限？**
只有两处用途：① 下载通道端点由用户自填（aria2 / iwaradl / MediaCenter 的地址无法预先写进清单）；② 钓鱼仿冒防护需要读取任意站点的主机名才能比对。其余只在 iwara.tv 上工作。

**扩展会不会上传我的数据？**
不会。没有开发者服务端、没有统计与远程日志；详见 [PRIVACY.md](https://github.com/dawn-lc/IwaraAssistant/blob/main/PRIVACY.md)。

**升级或重装后数据还在吗？**
同一扩展 ID 升级不会丢；只有「移除」扩展时浏览器才会连同数据一起清空。想备份就用「迁移」页签导出完整迁移包。
