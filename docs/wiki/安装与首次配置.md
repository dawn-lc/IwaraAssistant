# 安装与首次配置

## Firefox（推荐）

在 [AMO 产品页](https://addons.mozilla.org/firefox/addon/iwara-assistant/) 点「添加到 Firefox」，确认权限即完成安装，后续随版本自动更新。

- 最低 **Firefox 128**（`strict_min_version`），更低版本 AMO 会拦下。
- 上架包是 **MV2**，所以局域网里的 aria2 直接用 `http://192.168.x.x:6800/jsonrpc` 就行，不受 MV3 本地网络限制。
- 商店版本要过审，通常比仓库最新提交晚一两天；想立刻用主干代码就走下面的临时载入。

临时载入最新代码：

```bash
npm install    # Node >= 20.11
npm run build  # → dist/chrome、dist/firefox 与对应 .zip
```

打开 `about:debugging#/runtime/this-firefox` →「临时载入附加组件」→ 选 `dist/firefox/manifest.json`。临时载入的扩展在 Firefox 退出后失效，重开需重新载入。

## Chromium 系（Chrome / Edge / Brave / Vivaldi / Opera）

商店里没有（2026-10-30 被拒，见 [README 的说明](https://github.com/dawn-lc/IwaraAssistant#为什么不在商店里)），只能手动加载一次：

1. `npm run build:chrome`（或直接下载 CI 产物），产物在 `dist/chrome`。
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开右上角「开发者模式」。
3. 「加载已解压的扩展程序」→ 选**直接含 `manifest.json`** 的那个目录（选它的上一级会加载失败）。
4. 刷新已经打开的 iwara 页面。

更新时替换目录内容后点扩展卡片上的刷新按钮即可，配置与队列不会丢（同一扩展 ID）。完整步骤与故障排查见 [docs/07-install-chromium.md](https://github.com/dawn-lc/IwaraAssistant/blob/main/docs/07-install-chromium.md)。

## 首次配置（四步）

点工具栏图标 → 「设置」打开扩展选项，先在「下载」页签把四件事定下来：

| #   | 项目             | 说明                                                                                                                     |
| --- | ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 1   | **下载方式**     | 默认「浏览器内建下载」。想要多连接与断点续传就选 aria2（需先配端点）；iwaradl 同理；「打开直链」只交付一次、之后不再追踪 |
| 2   | **保存路径模板** | 默认 `/Iwara/%#AUTHOR#%/%#TITLE#%[%#ID#%].mp4`，变量见 [[路径可用变量]]，输入框下方有实时预览                            |
| 3   | **同时下载数**   | 只作用于浏览器通道，1~10，默认 3                                                                                         |
| 4   | **端点与密钥**   | 选 aria2 / iwaradl 时在「RPC」页签填写，并用页内的「端点与环境自检」确认连通                                             |

其余页签按需：过滤（列表改写）、清洗（文件名规则）、好友、迁移、高级（实验功能、界面语言、后台保活）、引导。

## 装完之后

- **必须刷新 iwara 标签页**：扩展在安装或更新后不会注入已经打开的页面。
- 打开任意视频列表页，右下角会出现悬浮菜单；菜单里可开关卡片复选框。
- 系统通知是唯一的结果反馈通道，请在操作系统里允许浏览器通知（被压掉不影响任务，但你会看不到结论）。
- 遇到问题先看 [[常见问题]] 与仓库的 [故障排查](https://github.com/dawn-lc/IwaraAssistant/blob/main/docs/10-troubleshooting.md)。
